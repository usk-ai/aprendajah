# aprendajah
Pasta de trabalho em desenvolvimento avançado em tecnologias de construção de aplicações para aprendizado guiado. O repositório será mantido como uma base atualizada diariamente para maior aproveitamento dos alunos.
## Dicionário Dev - AprendaJah 🚀

Plataforma PWA voltada ao aprendizado guiado de termos técnicos da área de tecnologia.

### 🛠️ Tecnologias e Ferramentas
- **Frontend:** React.js / Vue.js (Vite)
- **Offline:** Service Workers & Workbox
- **Estilização:** Tailwind CSS
- **IDE Recomendada:** VS Code

## 🚀 Como Executar
1. Instale as dependências:
   ```bash
   npm install ```
